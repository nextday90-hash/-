خەتم و زیکر — ڕێنمایی دانان وەک ئەپ (PWA)
==========================================

ناوەڕۆکی ئەم فۆڵدەرە:
  index.html            خودی ئەپەکە (هەموو قورئان و زیکرەکان تێیدایە)
  manifest.webmanifest  ناو و ئایکۆنی ئەپ
  sw.js                 وا دەکات ئەپەکە دوای یەکەم جار بێ ئینتەرنێتیش کاربکات
  icons/                ئایکۆنەکان (لۆگۆکەت)

پێویستە لەسەر ماڵپەڕێک دابنرێت (HTTPS)، چونکە ئایفۆن و ئەندرۆید تەنها لەو حاڵەتەدا
ڕێگە دەدەن وەک ئەپ دابمەزرێت. هەموو ئەمانەی خوارەوە خۆڕاین.

------------------------------------------------------------
ڕێگای ١: Netlify (ئاسانترین، بێ کۆد)
------------------------------------------------------------
1. بچۆ بۆ  app.netlify.com/drop  و ئەکاونتێک دروست بکە (بە Google یان ئیمەیڵ).
2. فایلی ZIPـەکە وەک خۆی (بێ کردنەوە) ببە بۆ ناو ڕووبەری Drop، یان لە مۆبایل
   دوگمەی «Browse to upload» بکە و فایلی ZIPـەکە هەڵبژێرە.
   (ئەگەر لەسەر مۆبایل نەبوو، لەسەر کۆمپیوتەر ZIPـەکە بکەرەوە و فۆڵدەرەکە ڕابکێشە.)
4. چەند چرکەیەک دواتر لینکێکت پێدەدات، وەک  xxxx.netlify.app
5. لە «Site configuration» دەتوانیت ناوەکە بگۆڕیت بۆ شتێکی جوان، وەک khatm-zikr.netlify.app

------------------------------------------------------------
ڕێگای ٢: GitHub Pages
------------------------------------------------------------
1. لە github.com ئەکاونتێک دروست بکە، ئینجا New repository (بە ناوی khatm-zikr، Public).
2. هەموو فایلەکان و فۆڵدەری icons بار بکە (Add file → Upload files) و Commit بکە.
3. Settings → Pages → Branch: main، فۆڵدەر: /(root) → Save.
4. دوای نزیکەی یەک خولەک لینکەکەت دەبێت:  ناوی-تۆ.github.io/khatm-zikr

------------------------------------------------------------
دانان لەسەر مۆبایل
------------------------------------------------------------
ئەندرۆید (Chrome):  لینکەکە بکەرەوە → سێ خاڵ → «Install app» یان «Add to Home screen».
ئایفۆن (Safari):     لینکەکە بکەرەوە → دوگمەی Share → «Add to Home Screen».
    (لەسەر ئایفۆن دەبێت لە Safari بکرێتەوە، نەک Chrome.)

------------------------------------------------------------
گرنگ
------------------------------------------------------------
* داتاکانت (خەتم، ئامار، زیکر) لەسەر هەر ناونیشانێک جیاوازن. کاتێک لە لینکی کۆنەوە
  دەگوازیتەوە بۆ لینکی نوێ:
    لە لینکی کۆن:  ڕێکخستن (ئایکۆنی چەرخ) ← پاشەکەوت و گەڕاندنەوە ← «کۆپیکردنی پاشەکەوت»
    لە لینکی نوێ:   هەمان شوێن ← بیلکێنە ← «گەڕاندنەوە»
* کاتێک index.html بگۆڕیت و دووبارە بارکردنەوە بکەیت، لە sw.js ژمارەی
  CACHE_VERSION بگۆڕە (نموونە: khatm-zikr-v2) بۆ ئەوەی مۆبایلەکان وەشانە نوێیەکە وەربگرن.
* یادخەرەوەکان (سورەتی کەهف، زیکری بەیانی، مولک) پەنجەرەیەک نیشان دەدەن کاتێک ئەپەکە
  دەکەیتەوە. ئەم وەشانە ناتوانێت لەسەر شاشەی قوفڵی مۆبایل دەرکەوێت. ئەو کارە پێویستی بە
  ئەپی ئەندرۆیدی ڕاستەقینە هەیە (ئایفۆن ڕێگەی پێ نادات).
